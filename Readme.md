# Audio Connection Monitor

A lightweight, minimalistic, and fully customizable Windows desktop widget that monitors your microphone input and speaker output in real-time. 

Unlike heavy audio mixing software, this tool is designed to be a simple, floating visual indicator giving you immediate confirmation that your audio hardware is picking up sound.

## Features
* **Real-Time Monitoring:** Dual-channel visual volume bars for your default microphone and speakers.
* **Smart Hot-Swapping:** Instantly detects when you connect or disconnect devices (like Bluetooth headphones) and seamlessly reconnects the visual audio stream.
* **Privacy First:** This app operates completely offline. It reads the local Windows Volume API and never records, saves, or transmits your audio.
* **Ghost Mode:** Remove the app background entirely for a borderless, floating UI that blends perfectly into your wallpaper.
* **Fully Customizable:** Includes a Dark/Light mode toggle, a master opacity slider, and a native Windows color picker to match your exact desktop aesthetic.

## How to Use
1. Double-click `audio_monitor.exe` to launch the widget.
2. **Move:** Click and drag anywhere on the application (or the pill frames if Ghost Mode is active) to move it around your screen.
3. **Customize:** Click the ⚙️ icon in the top right corner to open the Settings panel.
4. **Close:** Right-click anywhere on the widget's background.
